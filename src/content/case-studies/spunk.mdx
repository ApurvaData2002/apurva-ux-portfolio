    heading: "One app for being single and being together"
    layout: stacked
    paragraphs:
      - "Spunk’s brief covered more than the match. It needed to help people meet, start talking and, if it worked out, move into a shared couple space without leaving the app."
      - "That meant two modes, single and couple, plus the moments that move people between them: inviting a partner, making it official, and going back to single mode."
      - "The scope: onboarding and auth, Discover, Chat, Couple mode, and Profile, settings, subscription and support."
  - eyebrow: "Structure"
    heading: "Five numbered flows"
    layout: split
    image: /case-studies/spunk/section-02.png

    alt: "Two Spunk sign-up screens: step 2 of 5, Create your Spunk dating profile, with gender, orientation and what you’re looking for, and step 4 of 5, Show your best self, with photo slots and a bio field."
    paragraphs:
      - "I organised the canvas into five numbered flow sections and gave every screen a code (for example “1.4.02 Setup · Create dating profile”), so reviews and handoff could point to exact screens."
      - "I renamed key inner layers consistently so Smart Animate transitions still pair between screens."
      - "Empty, error and edge states sit next to the happy path: no matches yet, incorrect OTP, face didn’t match, payment failed."
  - eyebrow: "Key flows"
    heading: "Things to do in chat"
    layout: stacked
    image: /case-studies/spunk/section-03.png

    paragraphs:
      - "Conversations stall when nobody knows what to say, so chat threads include card decks, adventures and games like Roulette and the Vault for matches and couples to play together."
      - "“Right Now” lets people go live when they’re free to meet, and Spunks let them send a stand-out like."
      - "Safety stays one tap away in every thread: unmatch, block, and vanish chats."
  - eyebrow: "Design decisions"
    heading: "Your profile is the edit preview"
    layout: split
    image: /case-studies/spunk/section-04.png
    imageMobile: /case-studies/spunk/section-04-wide.png
    alt: "Two Spunk Edit profile screens: the Edit tab with profile strength and photo slots, and the Preview tab showing the profile exactly as others see it."
    paragraphs:
      - "For Edit profile I followed Bumble’s edit pattern, reworked in Spunk’s own style, using Mobbin as reference."
      - "The profile screen is also the preview for Edit profile, so people see exactly what others will see."
      - "Long edits are split into short, stepped sheets (e.g. About me 1/5), with chip rules and live counters driven by prototype variables."
  - eyebrow: "Solution"
    heading: "One clickable prototype across all five flows"
    layout: stacked
    image: /case-studies/spunk/section-05.png
    alt: "Three Spunk screens: You’re connected, opening the shared couple space, the couple Memories feed with an AI recap video, and a member’s profile."
    paragraphs:
      - "Every flow is wired into a single prototype: onboarding and auth, Discover / Right Now / Spunks, Chat, Couple mode, and Profile / settings / subscription / support."
      - "An interactive-components pass replaced one-off frames with stateful components, so chips, toggles and counters behave like the real thing."
      - "Couple mode adds memories, a shared album and couple chat, with a clear path back to single mode."
  - eyebrow: "Outcome"
    heading: "What I took away"

      - "What I’d test next: whether the “Show me” setting in Filters and in Edit profile should be one shared preference."
